### Как устоновить проект 🤫
<hr>

1. Шаг: для начала копируем репозиторий к себе
```bash
git clone https://github.com/pitomka/PR12-readme-file
cd PR12-readme-file
```
2. Шаг: Заходим для вас удобный редактор кода, где есть терминал
3. Шаг: вам нужен менеджер пакетов **npm** для установки зависимостей, скачать его можно по ссылке [npm](https://www.npmjs.com)
4. Шаг: после того, как вы зашли в редактор и установили npm, прописываем в терминале
```npm
npm install // или можно npm i
```
5. Шаг: запускаем проект!
```npm
npm run dev
```
6. Шаг: откроется ваш внутренний сервер ссылка на локальный хост [localhost:3000](localhost:3000), по которому будет доступен сайт
